# declarative-iac

Manuscript of a technical report on **declarative infrastructure management over procedure-oriented
APIs**, with [dokploy-iac](https://github.com/bernard-ng/dokploy-iac) and the Dokploy tRPC API as the
reference implementation.

Working title: *Declarative management over procedure-oriented APIs: kind specifications as a
semantic bridge*.

The reference implementation lives in its own repository and is cited at a pinned commit
(tag `eval-B1`, commit `5d73d4b`). This repository holds only the paper.

## Layout

```text
paper/
  outline.md                 title, paper type, section status
  sections/                  one Markdown file per section (00-abstract … 11-conclusion)
  references.bib             references (DOI-verified)
  figures/  tables/          empty until a section needs them
docs/literature-review.md    related work and positioning behind section 2
.agents/skills/              research-writing skills (mirrored in .claude/skills/)
```
